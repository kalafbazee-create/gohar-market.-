گهر مارکت نسخه ۹ - اسکن پیوسته با صدای تأیید

- بعد از خواندن هر QR یا بارکد، دوربین بسته نمی‌شود.
- با هر کد تازه صدای دینگ کوتاه پخش می‌شود.
- در صفحه فاکتور، مشخصات کالا نشان داده می‌شود و کاربر با دکمه افزودن، آن را تأیید می‌کند.
- پس از افزودن، اسکنر باز می‌ماند تا کالای بعدی اسکن شود.
- کد یکسان تا حدود ۱.۶ ثانیه دوباره ثبت نمی‌شود تا یک کالا چندبار ناخواسته اضافه نشود.
- با دکمه «بستن دوربین» اسکن تمام می‌شود.

فایل‌های index.html و sw.js و manifest.webmanifest را در ریشه مخزن GitHub جایگزین کنید.
قبل از جایگزینی از محصولات پشتیبان بگیرید. این نسخه از کلید ذخیره‌سازی قبلی محصولات استفاده می‌کند.
برای اسکن، اینترنت جهت بارگذاری کتابخانه ZXing لازم است.
