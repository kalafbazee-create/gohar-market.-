# گهر مارکت (Gohar Market)

اپ فروشگاهی فارسی برای مدیریت کالا و ثبت فاکتور با اسکن سریع بارکد.

## اجرا
```bash
flutter pub get
flutter run
```

## ساخت APK
```bash
flutter build apk --release
```

> برای دوربین، AndroidManifest به صورت خودکار با پکیج mobile_scanner تنظیم می‌شود؛ در صورت استفاده از نسخه‌های خاص Flutter/Android ممکن است حداقل SDK را مطابق مستندات پکیج تنظیم کنید.

## امکانات
- افزودن کالا با اسکن بارکد و تعیین قیمت
- ثبت فاکتور با اسکن پشت‌سرهم
- نگه‌داشتن اسکنر باز بعد از هر اسکن
- صدای دینگ بعد از اسکن موفق
- افزایش تعداد با اسکن دوباره
- جستجوی کالا
- ذخیره محلی کالاها و فاکتور جاری
- رابط کاربری فارسی و RTL
